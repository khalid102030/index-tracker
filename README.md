# 📡 متابعة المؤشرات — Index Tracker

نظام مستقل لتحليل المؤشرات الفنية وإصدار توصيات مُقيّمة بالذكاء الاصطناعي.

## المسار

```
Google Sheets / Excel → المحلل الرياضي (150+ مؤشر) → المُقيّم (Claude) → 3–5 توصيات → تتبع + تعلّم
```

## التشغيل

```bash
pip install -r requirements.txt
python server.py
```

## الإعدادات المطلوبة

| الإعداد | الوصف |
|---|---|
| رابط Google Sheets | شيت عام · كل تبويب = لقطة بتاريخ `2026-07-25_15-43` |
| مفتاح Claude API | للتقييم النهائي |
| Supabase URL + Key | لتخزين التوصيات والتتبع |

## الملفات

| الملف | الوظيفة |
|---|---|
| `server.py` | الخادم + كل الـ APIs |
| `evaluator.py` | حارس البوابة — Claude يقيّم ويختار 3–5 فقط |
| `indicator_analyzer.py` | المحلل الرياضي — أعلى-3 إشارات، كشف الفخاخ |
| `tracker.py` | تتبع التوصيات (3 أيام + 14 يوم متابعة) |
| `sheets_reader.py` | قارئ Google Sheets |
| `market_clock.py` | ساعات السوق السعودي |
| `web/index.html` | الواجهة |
